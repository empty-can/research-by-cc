# Q0 集計表

## 本ファイルの目的

Phase 0b-2-α（Q0 一斉実施フェーズ）で 20 サービスから取得した Q0 自己申告（学習時点 / MCP 知識正確性 / 知識解像度）を一覧化し、Phase 0b-2-β（戦略決定）の根拠資料とする。Phase 0b-2-γ（Q1 以降の本実施）の運用方針（採用 / 不採用 / 素材化のみ等）はここで決定する。

## 運用ルール

### 記入タイミングと担当

- 各列の記入は **Claude が AI 質問結果票（`AI質問結果/AI質問結果_NN.AI名.md`）の Q0 / Q1 以降回答から転記・要約する** 運用とし、作業指示者の記入負荷を抑える
- 記入タイミングは以下のいずれか:
  - 集計表初期化時（Phase 0b-2-α 着手時に先行記入できる列を埋める）
  - 作業指示者が AI 質問結果票のレビューを Claude に依頼したとき（同時更新）
  - Q0 のみ先行実施し、Q1 以降を別日実施するパターンでは、Q0 記入時点で先行更新

| 列 | 記入タイミング | 担当 | 備考 |

### 列の用途（分析時の使い道）

- **モデル提供形態**: Q0 自己申告（学習時点）との一貫性チェック / 学習データ鮮度の系統的傾向把握
- **モデル系統**: 信頼性スコアの「N LLM 言及 = 信頼度高」仮説における **系統重複の検出と層別化**（Claude 系 6 種等が独立 N 票でなく系統重複を含む可能性への対応）
- **Web 検索併用**: Q1 の CVE 列挙等で「学習データ由来」か「リアルタイム検索由来」かの切り分け

### 最終化フロー

- 20 サービスの Q0 が揃った時点で、表全体を俯瞰して判定基準を確定し、各行の採用判定・運用方針を最終化する
