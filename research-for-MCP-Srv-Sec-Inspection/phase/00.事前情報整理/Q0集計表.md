# Q0 集計表

## 本ファイルの目的

Phase 0b-2-α（Q0 一斉実施フェーズ）で 13 サービスから取得した Q0 自己申告（学習時点 / MCP 知識有無 / 知識解像度）を一覧化し、Phase 0b-2-β（戦略決定）の根拠資料とする。Phase 0b-2-γ（Q1 以降の本実施）の運用方針（採用 / 不採用 / 素材化のみ等）はここで決定する。

## 運用ルール

- 各 AI サービスへの Q0 質問が完了したら、本表に対応行を埋める
- 「自己申告学習時点」: AI が回答した時点情報を素直に転記（例: `2024-06`、`2024 年末頃`、`不明`）
- 「MCP 知識有無」: `有 / 無 / 部分的`
- 「MCP 知識解像度」: AI 自己申告内容を要約（例: `仕様概要のみ`、`個別 MCP サーバ CVE まで認識`、`Minecraft Control Panel と誤解釈` 等）
- 「採用判定」: `採用 / 不採用 / 保留`。理由を併記
- 「運用方針」: `通常運用 / Q1 スキップでハイブリッド / 素材化のみ / 質問取りやめ` 等
- 13 サービスの Q0 が揃った時点で、表全体を俯瞰して判定基準を確定し、各行の採用判定・運用方針を最終化する
