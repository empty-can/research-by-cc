### §4.1 二軸定義

**軸 A（検知軸）: コードインスペクションで検知可能か**

| 区分 | 定義 |
|---|---|
| A1 | 静的解析（SAST）で検知可能なコード実装不備（ハードコード秘密情報・インジェクション可能入力検証不足・既知脆弱ライブラリ依存等） |

## §5 統合過程で気づいた論点

### §5.1 同一性判定で迷った事例

**Semgrep vs Opengrep**:
- バッチ 1 §5.2 に既記録。Semgrep（全 10 件言及）と Opengrep（#13/#19 の 2 件言及）は別ツールとしてカウントを維持。Opengrep は「Semgrep の FOSS fork」として同一ファミリーだが、ライセンス・メンテナンス主体が異なるため別エントリを保持。

**mcp-scan の帰属表記差**:
- バッチ 1 §5.2 に既記録。「Invariant Labs」vs「Invariant Labs/Snyk」の表記差があるが同一ツール。バッチ 2 では Agent Scan (Snyk) が別ツールとして登場（`github.com/snyk/agent-scan`）。mcp-scan と Agent Scan は別物として扱う（§1.3 参照）。

**CVE-2026-21852 の同一性判定**:
- バッチ 1 では #20 のみが言及（Claude Code API キー窃取）。バッチ 2 では #01 が同一 CVE を言及。統合後は 2/10 の低信頼性として扱う。両バッチとも 2026 年 CVE フラグが立つため、Phase 1 での NVD 確認が必要。

**njsscan vs Nodejsscan**:
- バッチ 1 では `njsscan`、バッチ 2 では `Nodejsscan（njsscan）` として記載されていた。同一ツール（正式名 Nodejsscan、CLI 名 njsscan）と判断して 1 エントリに統合。言及 AI は #01/#10/#18（統合言及数 3）。

**OWASP GenAI Guides の同一性**:
- バッチ 1 §5.2 に既記録。バッチ 2 では `OWASP GenAI Secure MCP Server Development Guide` として URL 確認済みで言及（#21）。ガイドラインシリーズとして統合言及数 3（#19/#20/#21）で処理。

**Explore agent 由来（#16）の特殊性**: バッチ 1 で #16 の Explore agent が発見した GHSA 6 件は、バッチ 2 の Web 検索が活発な AI（#01/#13/#19/#21）が 1 件も言及しなかった。これは GHSA が NVD とは異なるインデックスであることが原因と推察されるが、逆に「Explore agent の検索対象が GitHub Advisory に偏っていた可能性」も否定できない。

### §5.3 系統横断で支持されているナレッジ vs 単一系統言及の傾向

**系統横断（3 系統すべてで言及）の傾向**:

1. **セキュリティの基礎ツール・フレームワーク**（OWASP LLM Top 10 / Bandit / Semgrep / Trivy）が全系統で共通言及。これらは「誰が調べても出てくる」普遍的なナレッジ
2. **攻撃概念**（ツールポイズニング / プロンプトインジェクション / SSRF / サプライチェーン攻撃）も系統横断。概念の実在性は疑問の余地なし
3. **CVE の系統横断率は低い**: CVE-2025-68143〜145 が唯一 3 系統での言及を達成した CVE（C=2/G=1/P=1）。他の CVE は 2 系統以下に留まる傾向

**Claude 系のみの傾向**:
- MCP 専用リソース（OWASP MCP Top 10 / MCP 公式仕様書 Security / CoSAI MCP Design Patterns）に偏る。Anthropic が直接関与するリソースへの高い感度は学習データの差を反映している可能性
- LLM テストツール（garak / promptfoo）が Claude 系のみ。AI セキュリティの実践的ツールへの言及が多い

**GPT 系（特に #14 ChatGPT）の傾向**:
- 概念・フレームワークの整理に強み（"trusted-but-malicious" / ケイパビリティ合成問題）
- 国際標準への言及（SLSA / ISO 29147/30111）は #13（Microsoft Copilot）固有で、ベンダー（Microsoft）の標準化志向を反映している可能性

**Gemini 系の特徴**:
- #10 Google Gemini 3 Flash は Web 検索なしでも学習データから安定して基礎ナレッジを提供
- #01 Google AI モード と #21 Gemini ブラウザ は Web 検索を活用するが URL 品質に注意（#01 の org 名誤り問題）
- 3 件とも共通言及するのは基礎ツール・概念系のみで、MCP 固有ナレッジは系統として弱め

### §5.4 疑義フラグ 2026 年 CVE の全体観

バッチ 1（1 件: CVE-2026-27735）から、バッチ 2 で大幅に増加（10 件）。統合後の 2026 年 CVE 総数は約 15 件。

| 系統 | 2026 年 CVE 提供 AI | 提供 CVE 数（概算） |
|---|---|---|
| Claude 系 | #19(★), #20(★) | #19 が多数 / #20 が一部 |
| Gemini 系 | #01(★), #21(★) | 各 2〜4 件 |
| GPT 系 | #13(★), #14(★) | #13 が 5 件前後 |

2026 年 CVE は採番・公開タイムラグを考慮する必要があるが、NVD 未確認 + 単一 AI 言及のものはハルシネーションリスクが高い。Phase 1 での個別検証が必要。
