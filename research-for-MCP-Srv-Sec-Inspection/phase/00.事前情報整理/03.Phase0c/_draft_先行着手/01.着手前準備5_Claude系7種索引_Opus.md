## 5. Plugin 有/無別索引

### 5.1 Plugin 有（16, 18）

- 観察される共通体裁:
  - Insight ブロック（`★ Insight ─────────────────────────...`）が回答末尾もしくは中間に挿入
  - ASCII art 風表組（罫線文字）が多用される傾向
  - 「Markdown 書式で出力」指示が一部無視される事例あり（16 で観察、Plugin 影響仮説）
- **モデル差による Insight ブロック内容の濃淡**:
  - 16 (Sonnet 4.6): 具体テクニック・実用 ROI 指針が中心（例: 「`== token` Semgrep ルール 1 本で ROI 最大」）
  - 18 (Opus 4.7): メタ的・運用論的・設計判断的（例: SARIF 統合方針、stdio→HTTP 移行時の保険型実装推奨）
  - **同じ Plugin 機能でもベースモデル個性が反映される**（質問者所感で 18 ファイル内に明記）

### 5.2 Plugin 無（19, 20）

- Q0.ex1 動作検証で確定（共通）

  - Insight ブロック皆無

  - check-model Skill 出力が混入することあり（環境固有の自動化）
- **Web 検索の挙動**: 両者とも積極活用。経由先より明示指示有無が支配的

### 5.3 Plugin 状態未確認（15, 17）

- いずれも Bedrock 経由 Claude Code 環境（16/18 と同環境）
