# discussion

このフォルダは、作業指示者が Claude Code と何らかの議論・検討をする際に利用するフォルダ

## 議論時のフォルダ作成ルール

議論をする際には、本フォルダ直下に以下の命名規則に従ったサブフォルダを作成し、その配下に議論の内容を記述したファイルや、議論の中で生成するファイル群を配置する。

* **サブフォルダの命名規則:**  
  `<議論事項の通番(Dxx)>-<要旨が分かる端的な記述>-<議論の開始日(YYYYMMDD)>\`
  * 区切り文字は半角ハイフン `-` を使用する（要旨内に半角スペースが入る場合は半角アンダーバー `_` で代替する）
  * 通番 `Dxx` は本ファイルの「通番管理」節で一元管理する。新規議論着手時に次の番号を採番し、本ファイルの該当値を更新する
  * 通番 `Dxx-` は `improvements/` 配下の要改善点 ID 接頭辞（同じ `Dxx-yyy` 形式）と一致させ、議論 ↔ 改善点の紐付けを直接的に行う

### 通番管理

| 項目 | 値 |
|---|---|
| 次に利用する議論通番 | D01 |

### 議論が複数のサブ論点を含む場合のルール

サブ論点ごとに、更にサブサブフォルダを作成し、その中で個々に議論する。  
ただし、サブ論点に関する議論から結論までが1つのファイルで完結する場合はサブサブフォルダを作る方が煩雑になり得るので、これは厳守ルールはなく推奨ルール。

* **サブサブフォルダを作成するか否かの判断基準と作成タイミング**
サブ論点の議論で2つ以上のファイル作成をすることになった際、初めてサブサブフォルダを作成する。

* **サブサブフォルダの命名規則:**  
  `<サブ論点の議論の通番+要旨が分かる端的な記述>\`
