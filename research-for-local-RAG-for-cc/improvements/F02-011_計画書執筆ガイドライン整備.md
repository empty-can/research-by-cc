# F02-011 計画書執筆ガイドライン整備

## 1. はじめに

### 1.1 要改善点概要

計画書というドキュメントは「全記載内容を時間をかけて十分にレビューする必要がある」性質のドキュメントであり、分量制約による読了時間制約は他ドキュメントほど厳格に適用すべきではない。代わりに、計画書固有の品質観点（ドキュメントの全体構成・各セクションの要点把握容易性・記載順序の理解容易性・必要情報の網羅性・判断基準/マイルストーン記載の適切性等）を、計画書執筆ガイドラインとして詳細整備する必要がある。

### 1.2 サマリ

| 項目 | 内容 |
| --: | :-- |
| **カテゴリ** | テンプレート運用 / 文書品質 |
| **優先度** | 中 |
| **スコープ** | 横断 |
| **ステータス** | 未対処 |
| **影響範囲** | 全フェーズの計画書（02 完了済み・03/04/05 で適用予定）。整備が完了すれば計画書のレビュー収束効率と承認判断品質が向上する |
| **関連 ID** | F02-010（資産性質改善）の派生。F02-012（調査報告書執筆ガイドライン整備）と並行して進める想定 |
| **採用案** | — |

## 2. 発生事象の整理

### 2.1 発生事象

§9.3 再執筆トライアル後の作業指示者からの追加リクエスト（`テンプレート検証_改訂提案_2026-05-05.md` §3.4.2 (1)）として、計画書というドキュメントの性質に対応する固有のレビュー観点を、計画書執筆ガイドラインとして整備する必要性が提起された。

主要な観点（作業指示者からのリクエスト原文）:
- ドキュメントの全体構成や各セクションの要点が把握しやすい文章構成になっているか
- 各セクションの記載順序は、理解容易性や妥当性のチェック容易性という面から適切か
- 必要な情報が漏れなく記載されているか
- その他、レビューアの指摘にあるような判断基準やマイルストーンなど計画遂行に必要な観点や方針についても漏れなく記載されているか

### 2.2 発生経緯

詳細な議論経緯は以下のファイルを参照:

- `reports/02.基礎調査/work/F02-009_F02-010_文章執筆およびレビュー品質改善/テンプレート検証_改訂提案_2026-05-05.md` §3.4.2 (1)（作業指示者からの追加リクエスト）

主要な経緯:
1. §9.3 再執筆トライアルでの v3 計画書執筆時に、執筆ガイドライン v1.0 適用効果を確認
2. レビュー結果から、計画書固有の観点が「分量より構成・順序・網羅性」に集中することを把握
3. 作業指示者から「計画書執筆ガイドライン」整備の必要性が提起され、本バックログを起票

## 3. 原因分析

### 3.1 直接原因

- 現状の `.claude/skills/writing-guideline/`（Skill 形式）は全ドキュメント共通のガイドラインであり、計画書固有の課題（性質に応じた読了時間制約の例外運用・判断基準/マイルストーンの必須記載項目など）の詳細整備が `references/計画書.md` に最低限の観点を整理した状態に留まる
- §4.1 計画書セクションは観点の列挙にとどまり、各観点の詳細チェックリスト・具体例・チェック手順が未整備

### 3.2 根本原因

> 対処着手時に `/5-whys` スキルで根本原因分析を実施予定。

## 4. 同件調査

> 対処着手時に実施予定。F02-012（調査報告書執筆ガイドライン整備）と並行調査することで、ドキュメント種別ごとの固有観点の体系化を進める。

## 5. 再発防止策

> 対処着手時に `/5-whys` の対策セクションを参照して案出予定。
> 暫定的な対応方向の素案として:
> - 計画書執筆ガイドラインの詳細化を、`.claude/skills/writing-guideline/references/計画書.md` の拡張、または別 Skill として独立配置のどちらで整備するか検討
> - 観点（§3.4.2 (1) のリスト）ごとにチェックリストと具体例を整備:
>   - ドキュメントの全体構成・各セクションの要点把握容易性
>   - 各セクションの記載順序の理解容易性・妥当性のチェック容易性
>   - 必要情報の網羅性（成功条件・打ち切り条件・スコープ・WBS・成果物・体制・スケジュール・リスク 等）
>   - 判断基準・マイルストーンなど計画遂行に必要な観点・方針の網羅性
> - 既存 `.claude/skills/writing-guideline/references/計画書.md` から新ガイドラインへのリンクを設置し、共通ガイドラインと固有ガイドラインの関係を明示

## 6. 特記事項/補足事項

- F02-012（調査報告書執筆ガイドライン整備）と並行整備することで、ドキュメント種別ごとの固有観点が体系化される
- 作業指示者レビュー報告のガイドライン・雛型は、後続フェーズの作業指示者レビューの中で別途整備される想定（バックログ起票対象外）
