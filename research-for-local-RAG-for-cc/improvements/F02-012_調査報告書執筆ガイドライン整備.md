# F02-012 調査報告書執筆ガイドライン整備

## 1. はじめに

### 1.1 要改善点概要

調査報告書（フェーズ報告書・統合報告書）というドキュメントの性質に対応する固有のレビュー観点を、調査報告書執筆ガイドラインとして詳細整備する必要がある。F02-011（計画書執筆ガイドライン整備）と並行して進めることで、ドキュメント種別ごとの固有観点が体系化される。

### 1.2 サマリ

| 項目 | 内容 |
| --: | :-- |
| **カテゴリ** | テンプレート運用 / 文書品質 |
| **優先度** | 中 |
| **スコープ** | 横断 |
| **ステータス** | 未対処 |
| **影響範囲** | 全フェーズの調査報告書（フェーズ報告書・統合報告書）。整備が完了すればレビュー収束効率と承認判断品質が向上する |
| **関連 ID** | F02-010（資産性質改善）の派生。F02-011（計画書執筆ガイドライン整備）と並行して進める想定 |
| **採用案** | — |

## 2. 発生事象の整理

### 2.1 発生事象

§9.3 再執筆トライアル後の作業指示者からの追加リクエスト（`テンプレート検証_改訂提案_2026-05-05.md` §3.4.2 (1)）として、F02-011（計画書執筆ガイドライン整備）と並行して、調査報告書執筆ガイドラインの整備が必要との判断から本バックログを起票。

### 2.2 発生経緯

詳細な議論経緯は以下のファイルを参照:

- `reports/02.基礎調査/99.最終基礎調査報告/レビュー/2026-05-05/テンプレート検証_改訂提案_2026-05-05.md` §3.4.2 (1)（作業指示者からの追加リクエスト）

主要な経緯:
1. §9.3 再執筆トライアルでの v3 統合報告書執筆時に、執筆ガイドライン v1.0 適用効果を確認
2. F02-010 の本格対処として執筆ガイドライン整備が完了したが、調査報告書固有のチェックリスト・具体例・チェック手順は未整備
3. 作業指示者から計画書執筆ガイドライン整備の必要性が提起された際、調査報告書についても同様の整備が並行して必要との判断（F02-011 と並行起票）

## 3. 原因分析

### 3.1 直接原因

- `ドキュメント執筆ガイドライン.md`（v2.0）の §4.2 調査報告書セクションは観点の列挙にとどまり、各観点の詳細チェックリスト・具体例・チェック手順が未整備
- 統合報告書追加観点（§4.2.1）は §9.3 トライアルで観察された問題（用語統一・章間整合・レイヤー間整合・状態同期等）を反映済みだが、これらの詳細整備（具体的な実施手順・チェックリスト）は将来的に必要

### 3.2 根本原因

> 対処着手時に `/5-whys` スキルで根本原因分析を実施予定。

## 4. 同件調査

> 対処着手時に実施予定。F02-011（計画書執筆ガイドライン整備）と並行調査することで、ドキュメント種別ごとの固有観点の体系化を進める。

## 5. 再発防止策

> 対処着手時に `/5-whys` の対策セクションを参照して案出予定。
> 暫定的な対応方向の素案として:
> - 調査報告書執筆ガイドラインを `research-for-local-RAG-for-cc/調査報告書執筆ガイドライン.md`（または `.claude/rules/` 配下）として **独立ファイルとして整備**（既存の `ドキュメント執筆ガイドライン.md` v2.0 §4.2 / §4.2.1 の拡張ではなく、参照容易性のため独立配置）
> - 観点（§4.2 / §4.2.1 ベース）ごとにチェックリストと具体例を整備:
>   - 「調査内容 / 調査結果 / 結論・示唆」の冒頭サマリ 3 部構成
>   - サブタスク間の用語統一・章間整合・レイヤー間整合
>   - ハマりどころ.md 等の状態同期
>   - GO/NO-GO 判断材料の整理（支持事実・NO-GO リスク・次フェーズ方針の 3 段構造）
>   - サブタスク報告書への参照容易性
> - 既存 `ドキュメント執筆ガイドライン.md` v2.0 §4.2 / §4.2.1 からは新ガイドラインへのリンクを設置し、共通ガイドラインと固有ガイドラインの関係を明示

## 6. 特記事項/補足事項

- F02-011（計画書執筆ガイドライン整備）と並行整備することで、ドキュメント種別ごとの固有観点が体系化される
- 作業指示者レビュー報告のガイドライン・雛型は、後続フェーズの作業指示者レビューの中で別途整備される想定（バックログ起票対象外）
