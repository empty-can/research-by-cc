# F02-009 クロスレビュー指摘記載ルールとセルフレビュー観点の規定

## 1. はじめに

### 1.1 要改善点概要

クロスレビューにおいてレビュー指摘の記載ルール（事実認定型 vs 表現改善型 / 根拠記述要件 / ラベル選定基準等）と、セルフレビューの観点（前半フェーズ＝新規 NG 検出 / 後半フェーズ＝誤検知チェック / Round 2 レビューイ視点 / Round 3 取り込み整合性）が明文化されていないため、レビューア・レビューイがセルフレビューを過剰に反復したり、誤検知的指摘の発生数が想定より多くなったりする傾向がある。これらのルール・観点を規定することで、誤検知発生の抑制とセルフレビュー収束速度の向上が期待できる。

## 2. 発生事象の整理

### 2.1 発生事象

2026-05-05 の改訂版クロスレビューテンプレート検証作業（02.99 報告書を対象とした 3 ラウンド対話型クロスレビュー）において、以下が観察された:

- 論理整合性レビューア（Opus）のセルフレビュー反復回数: **6 巡**
- 実用性レビューア（Sonnet）のセルフレビュー反復回数: **8 回**

このうち、誤検知チェックが主目的の反復が論理整合性で 3 巡 / 実用性で 7 回を占め、特に Sonnet は 1 回目の指摘候補（Ollama 制約に関する誤検知候補）を 1 巡目で取り消し、2〜4 巡目をラベル境界判定（IMPORTANT vs SUGGESTION）に費やしていた。

「指摘候補を一通り出し切る」フェーズと「出した指摘の誤検知チェック」フェーズが手順として分離されていないため、両者が混在して反復される傾向が観察された。

### 2.2 発生経緯

詳細な議論経緯は以下のファイルを参照:

- `reports/02.基礎調査/work/F02-009_F02-010_文章執筆およびレビュー品質改善/01.クロスレビューフローおよびレビュー報告書雛型整備/テンプレート検証_セルフレビュー運用考察_2026-05-05.md` §2.2「打ち切ったらどうなったか」の試算 / §2.4 (b) 「新規 NG 検出ゼロ」と「誤検知チェック」の分離

主要な経緯:
1. テンプレート検証作業のセルフレビュー反復回数の妥当性について作業指示者から問題提起（同 §0）
2. 一般論および今回実績の分析を経て、レビューアセルフレビュー上限を 3〜4 回程度で打ち切っても品質に影響しないとの見立て（同 §1〜§2.2）
3. 上限値設定に加え、上流での品質担保策として「指摘記載ルール」「セルフレビュー観点」の規定が有効と作業指示者から提案（同 §2.2 作業指示者の回答）
4. 必要性が感じられた場合に実施する位置付けで本バックログを起票（同 §2.2 / §4.5）

## 3. 原因分析

### 3.1 直接原因

- クロスレビューテンプレート（`.claude/templates/cross-review/`）には指摘エントリの構造（CRITICAL/IMPORTANT/SUGGESTION/POSITIVE）と修正案テーブル形式は定義されているが、**指摘の記載ルール**（事実認定型／表現改善型／根拠記述の要件レベル等）は未明文化
- セルフレビューの**観点**（何を確認すべきか）と**手順**（どの順序で確認するか）が未明文化
- 暫定的な上限値（前半 5 回 / 後半 Opus 3 回・Sonnet 4 回）を運用しても、観点規定の不在により誤検知の発生自体は抑制されない

## 5. 再発防止策

> 対処着手時に `/5-whys` の対策セクションを参照して案出予定。
> 暫定的な対応方向の素案として:
> - 指摘の記載ルール（事実認定型／表現改善型の区分・根拠記述要件・ラベル選定の補助基準）を `cross-review/README.md` に節として追加
> - セルフレビューの観点（前半＝新規 NG 検出フェーズ / 後半＝誤検知チェックフェーズ / Round 2 レビューイ視点 / Round 3 取り込み整合性）を同 README に追加
> - 規定後の試行で、現状暫定の上限値（特に Sonnet 後半 4 回）を再評価し、3 回統一を目指す

## 6. 特記事項/補足事項

- 本要改善点は「実施しないことによって致命的なコスト増加に繋がるリスクは少ない」（作業指示者見解、同考察ファイル §2.2）。**繰り返し上限を追加した運用で実際に支障が出たり、レビューアを担当したモデル（Sonnet 等）から要望があったタイミングで対処に着手すればよい**位置付け。
- 本要改善点が解消されると、暫定の上限値（特に Sonnet 後半 4 回）の値見直し（3 回への統一）が可能になる見込み。
