# Issue 運用ルール — research-for-local-RAG-for-cc

> このファイルは本調査（`research-for-local-RAG-for-cc/`）における GitHub Issue の運用ルールを定める。

- 作成日: 2026-05-02
- 作成者: Claude Code（Opus 4.7）
- 適用範囲: `research-for-local-RAG-for-cc/` 配下の調査活動

## 1. 適用範囲

本調査では、Issue は **以下に該当するものに限定して** 活用する（採用案: C 案 = 最小採用）。

| 対象 | Issue 化 | 備考 |
|---|---|---|
| 将来解決が必要な課題 | する | 本調査で完結しない・別活動で解決すべきもの |
| 解決不能課題（スコープ外確定・技術制約等） | する | 知見として残すべき項目 |
| 申し送り事項 | する | 本調査スコープ外で目的達成のために調査等が強く推奨される項目 |
| フィジビリティ検証中のフェーズ内課題 | しない | 従来通り報告書または別紙に記載 |
| その他フェーズ内で完結する課題 | しない | 報告書本文に記載 |

ブランチ運用（Issue に紐付けた解消用ブランチ作成）は **行わない**。

---

## 2. ラベル

### 必須ラベル

| ラベル | 用途 |
|---|---|
| `backlog` | 活動終了後に申し送る課題や残タスクであることを示す |

すべての Issue に `backlog` を必ず付与する。

### 追加ラベル候補

タイプを示すために、以下のいずれか 1 つを併用する:

| ラベル | 適用対象 |
|---|---|
| `課題-将来解決` | 将来解決が必要な課題 |
| `課題-解決不能` | スコープ外確定・技術制約等で本調査では解決不能な課題 |
| `申し送り` | 本調査スコープ外で目的達成のため調査等が強く推奨される事項 |

---

## 3. タイトル規則

```
[<フェーズ番号>][<タイプ>] <短い課題タイトル>
```

- `<フェーズ番号>`: `01` / `02` / `03` / `04` / `05` / `99`（フェーズ横断の場合は `全体`）
- `<タイプ>`: `将来解決` / `解決不能` / `申し送り`
- `<短い課題タイトル>`: 1 行で内容が把握できる簡潔な記述

例:
- `[04][将来解決] Docker ランタイム未整備環境での pgvector 検証保留`
- `[全体][申し送り] 命名規則の汎用ルール化（タスク／フェーズ／作業 階層）`

---

## 4. 本文テンプレート

```markdown
## 内容

<課題そのものの簡潔な説明>

## 背景・経緯

<Issue として起票されるに至った背景・経緯>

## クローズするために実施が必要な対応

<クローズに必要な作業内容を箇条書きで記載>

## 参考情報

<関連する外部情報やリポジトリ内成果物へのリンク>
```

---

## 5. クローズ条件

課題タイプごとに以下の条件で扱う。

| タイプ | クローズ条件 |
|---|---|
| `課題-将来解決` | 課題の解決が完了した時点 |
| `課題-解決不能` | 報告書（本調査の最終報告書または該当フェーズ報告書）に「解決不能」分類で記載完了した時点。Issue 自体は `backlog` のまま残し、参考用としてオープンで残す運用も可（本調査の最終報告書での承認をもって扱いを決定） |
| `申し送り` | 申し送り先（別活動）で対応が完了した時点。本調査の範囲を超えるため、本調査としては「最終報告書に申し送り事項として記載完了」をもってクローズ可とする |

クローズ判断は **作業指示者の承認** をもって行う。

---

## 6. マイルストーン

本調査での Issue 適用範囲は限定的なため、マイルストーンの利用は **最小限** に留める。

- 各フェーズ完了タイミングや活動完了タイミングのマイルストーンを設定する **必要があると判断した場合のみ** 設定する。
- マイルストーン未設定でも運用上問題なし。

---

## 7. 報告書との関係

報告書側には Issue のタイトルとリンクのみ記載することで、報告書の肥大化を防ぐ。

- 報告書本文の「課題」「申し送り事項」セクションには、`#<Issue 番号> <Issue タイトル>` 形式でリンクを張る。
- 課題の詳細（背景・対応事項・参考情報）は Issue 側に集約する。

---

## 8. 運用範囲

本ルールは **本調査（`research-for-local-RAG-for-cc/`）における運用** を定めたものである。
他の調査・活動への一般化は **申し送り** とし、本調査終了後に検討する。
