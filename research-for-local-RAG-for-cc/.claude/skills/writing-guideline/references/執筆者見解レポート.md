# 執筆者見解レポート

ドキュメント執筆完了時、執筆者が別ファイルとして作成することを推奨するレポート。レビューア（クロスレビューを実施する別 Agent）が執筆者の意図を把握した上でレビューに入るための参考資料。

## 1. レポートの目的

執筆者の意図が見えていれば、レビューア側が「単なる形式指摘」と「設計意図への反論」を区別しやすく、レビュー収束が早まる。執筆ガイドライン改善のフィードバックループを駆動する仕組みでもある。

## 2. レポートに含めるセクション

| セクション | 記載内容 |
|---|---|
| **執筆過程の所感** | ガイドライン適用しやすさ・困難点 |
| **ガイドライン改善案** | 観点単位での具体的改善提案（次版反映候補） |
| **セルフチェック結果サマリ** | G3-1〜G3-11 の各観点遵守状況、情報欠落チェック結果 |
| **構造的差分の自己分析**（再執筆時） | 旧版との章立て変更点、削除箇所、追加箇所、その理由 |
| **典拠評価**（統合報告書時） | サブタスク報告書 N 件の質・量・整合性・統合のしやすさ |

## 3. ファイル名規則

`<対象成果物名>_執筆者見解_<日付>.md` または同等。対象成果物と並列に配置する。

```
例:
reports/02.基礎調査/99.最終基礎調査報告/
├── 報告書.md
└── 報告書_執筆者見解_2026-05-06.md
```

## 4. 活用方法

1. レビューア（クロスレビューを実施する別 Agent）が執筆者見解を参考資料として読み、執筆意図を把握した上でレビューを行う
2. ガイドライン改善案は次版改訂時の入力として活用
3. 構造的差分の自己分析は、改訂レビュー時の作業指示者判断材料となる
