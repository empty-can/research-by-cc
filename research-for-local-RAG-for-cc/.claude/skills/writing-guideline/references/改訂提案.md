# 改訂提案・運用考察ドキュメント 固有観点

改訂提案ドキュメント・運用考察ドキュメント執筆時に共通観点（`common/01〜03`）に加えて適用する追加観点。

## 1. 完成前セルフチェックフェーズの追加観点

### 1.1 Devil's Advocate を改訂方針ごとに 1 件

G3-7 Devil's Advocate を改訂方針ごとに 1 件ずつ実施。改訂提案は採用判断の根拠となるため、反論棄却の論証が承認可否に直結する。

### 1.2 改訂量と効果のバランス・実装難易度を明記

各改訂方針について以下を明記する:

- **改訂量**: 既存資産への変更行数・変更ファイル数の目安
- **効果**: 改善される観点・想定される指標改善
- **実装難易度**: 機械的反映可能 / 個別判断必要 / 大規模リファクタ等の区分

```markdown
例:
### B1: 観点 N の文言整理
- **改訂量**: 3 ファイル・約 30 行
- **効果**: レビュー段階での「文言曖昧」指摘を予防（観点 N 関連指摘の約 80% 削減見込み）
- **実装難易度**: 機械的反映可能
```

### 1.3 既存資産への影響範囲を明記

改訂方針が既存資産（過去の報告書・別の改訂提案・運用ルール 等）にどう影響するかを明記する。

- **影響なし**: 新規追加項目で既存に変更不要
- **既存資産の参照先のみ更新**: 既存資産自体は変更せず、参照リンクのみ更新
- **既存資産の本文更新が必要**: 該当ファイル・該当節を列挙
- **既存資産との互換性**: 旧版でレビュー済み資産は機械的置換せず、新規執筆ドキュメントから適用 等

> **理由**: 改訂提案の採用可否判断には「既存資産への波及」が重要な判断材料。影響範囲が不明だと、採用判断が保留されたまま改訂が滞る。
