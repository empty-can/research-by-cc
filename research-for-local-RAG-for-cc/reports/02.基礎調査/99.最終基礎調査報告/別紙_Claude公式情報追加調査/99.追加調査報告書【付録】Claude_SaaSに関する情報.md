## 1. Projects RAG（起点記事の主題機能）

### 概要

Claude.ai の **Projects 機能** の自動拡張モード。Project の knowledge base にアップロードされたコンテンツが context window 上限に近づいた際、Claude が自動的に「project knowledge search tool」を使ってアップロード文書から関連箇所だけを取得するように切り替わる仕組み。容量を最大 **10x** まで拡張する。

### 主要数値

- 対応プラン: 全プラン対応（Free / Pro / Max / Team / Enterprise）と明記
- Free プラン: **最大 5 projects** まで
- RAG 拡張: 有料プラン限定
- 利用環境: **claude.ai (Web UI) 専用**。API 経由・Claude Code 経由のアクセス手段は公式ドキュメントに記載なし

### 内部実装（記事の言及範囲）

- 検索手法: **明記なし**（"project knowledge search tool" としか表現されていない）
- チャンク化方針: 明記なし
- 埋め込みモデル: 明記なし
- ストレージ: 明記なし（Anthropic 内部管理）

### Claude Code との関係

**Claude Code から呼べる公式 API 経路は存在しない**（パンくず: `All Collections > Claude > Features and capabilities > Retrieval augmented generation (RAG) for projects`、Claude Code コレクションには該当機能の記事なし）。

## 2. Context Window（参考情報・本紙にも一部記載）

### 概要

Projects RAG が「いつ起動するか」の閾値を理解するための背景情報。

### 主要数値（claude.ai での値）

- 標準モデル context window: 200K tokens（有料プラン、~500+ pages 相当）
- 拡張モデル（Sonnet 4.6 / Opus 4.6 / Opus 4.7）: **500K tokens**（全有料プランのチャット）

### Claude Code 経由の特例値（本紙でも参照される）

- Opus 4.7: **1M tokens**（Pro / Max / Team / Enterprise の Claude Code）
- Sonnet 4.6: **1M tokens**（全有料プランの Claude Code、Pro は追加 usage 必要）

→ 本紙 §3 / §5 の CAG パターン関連議論で参照される（Claude Code の拡張 context window がカバーする範囲）

### 詳細出典

## 3. Claude Projects（RAG の宿主機能）

### 概要

「self-contained workspaces with their own chat histories and knowledge bases」。knowledge base に文書をアップロードし、project 内全チャットから参照可能。knowledge base が一定量を超えた時、内部で Projects RAG（§1）に自動切替。

### 制約

- 「documents, text, code, or other files」とのみ記述。具体形式・サイズ・件数は記事に明記なし
- Free プラン 5 projects 上限
- **claude.ai UI 専用**。API 経由・Claude Code 経由のアクセスは記事に明記なし

### Team / Enterprise の追加機能

- Project visibility: private / organization-wide
- メンバー権限: can view / can edit

### Chats 間の知識共有

> "Context is not shared across chats within a project unless the information is added into the project knowledge base."

→ knowledge base への投入が project 内チャット横断の知識共有の唯一手段

### 詳細出典

`01.公式サポート記事調査_Agent-A.md` §3（Claude Projects）

## 4. Google Workspace Connectors（Drive Cataloging）

### 概要

Claude チャットから Gmail / Calendar / Drive を操作可能。**Drive Cataloging** モードでは Anthropic が Google Docs を indexing し、conversation 時に index を参照する RAG ベース機能。

### 主要数値

- Drive Cataloging 対応ファイル: **Google Docs のみ、10 MB まで**
- 利用可能プラン: **Enterprise 限定**（Drive Cataloging のみ。基本機能は全プラン）
- 利用環境: claude.ai / Claude Desktop（API 経由は記事に明記なし）

### 詳細出典

`01.公式サポート記事調査_Agent-A.md` §4（Google Workspace Connectors）

## 5. Chat Search & Memory（claude.ai 機能）

### Chat Search

- 過去会話を検索する RAG ベース機能（公式記事で "Retrieval-Augmented Generation (RAG)" を使うと明記）
- 利用可能プラン: Pro / Max / Team / Enterprise（Free 不可）
- 提供面: claude.ai web / Claude Desktop / Claude Mobile
- **API・Claude Code からの利用: 記事には明記なし**
- 内部手法（semantic / keyword / embedding）: 明記なし

### Memory（claude.ai 機能）

- 24 時間ごとに会話を自動 synthesize、key insights を保存
- 利用可能プラン: 全プラン
- conversation data と同じ場所に保存（Enterprise は at-rest 暗号化）
- 元 chat 削除時に連動削除
- **本機能は Anthropic Messages API の Memory tool（`memory_20250818`）とは別物**（本紙 §2.2 参照）

### 詳細出典

## 6. Claude SaaS と Claude Code の RAG / 知識管理機能 対比表

本付録の総括として、Claude SaaS の RAG / 知識管理機能と Claude Code の対応機能（または対応物の有無）を対比する。

| 機能カテゴリ | Claude SaaS | Claude Code | Claude Code から SaaS 機能の利用 |
|---|---|---|---|
| ファイル知識ベース | Projects（5〜∞ プロジェクト、自動 RAG 拡張） | **同等機能なし**（CLAUDE.md / MEMORY.md による静的ロードのみ） | **不可**（API 経路なし） |
| 大容量データの検索 | Projects RAG（10x 拡張） | **同等機能なし**（Filesystem Exploration / MCP server 連携で代替） | **不可** |
| Google Drive 統合 | Drive Cataloging（Enterprise） | **同等機能なし** | **不可** |
| 会話履歴検索 | Chat Search（Pro 以上） | **同等機能なし**（auto memory は別概念） | **不可** |
| 永続記憶 | Memory（24h 自動 synthesize） | auto memory（`~/.claude/projects/<project>/memory/`） | **不可（SaaS 側 Memory への直接アクセスなし）** |
| 検索結果の引用 | Projects RAG 内で自動 citation | **標準機能なし**（API の Search results blocks + Citations 経由が本来。ただし Claude Code 経由不可と本紙 §2.2 で確証済み） | **不可** |

→ **Claude SaaS の RAG / 知識管理機能と Claude Code の標準機能は、ほぼ完全に独立した別系統**。Claude SaaS 側の機能を Claude Code から利用する公式手段は本調査では確認できなかった。本調査で構築するローカル RAG は Claude SaaS とは独立した、Claude Code 専用の知識検索基盤としての位置付けとなる。
