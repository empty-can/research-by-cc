### A3.「Anthropic Messages API レイヤを Claude Code から間接利用する公式ルートは存在しない」の確証記録

- **指摘元**: 作業指示者（2026-05-17 セッション内、仮説提示）
- **背景**: 「Claude Code → MCP server → Anthropic Messages API」という公式利用フローが存在するか作業指示者から仮説提示。メインセッションで以下 4 経路を WebFetch + Grep で確認し、**存在しないことが強く示唆される**と判定:
  1. MCP プロトコル設計思想（modelcontextprotocol.io トップ）: 「AI アプリ → 外部システム」方向、LLM API への二次アクセスは設計範囲外
  2. 公式 MCP サーバ実装一覧（`modelcontextprotocol/servers`）: Reference Servers 7 件（Everything / Fetch / Filesystem / Git / Memory / Sequential Thinking / Time）に Anthropic Messages API / Files API / Citations / Anthropic Memory tool 提供サーバなし
  3. Anthropic 公式「MCP connector」（`platform.claude.com/docs/en/agents-and-tools/mcp-connector`）: 方向は「Messages API → MCP server → 外部システム」で逆方向、ローカル STDIO サーバは直接接続不可（HTTP/SSE のみ）
  4. Claude Code 公式 docs Grep: 該当利用フローへの言及ゼロ
- **修正対象**:
  - [ ] 再定義後の第 3 部「設計時の制約事項」に新規節として追加（仮称: §3.X「Anthropic Messages API レイヤを MCP 経由で利用する公式ルートは存在しない」）
  - [ ] §1.1 三層レイヤ整理表の「Anthropic Messages API」レイヤ行に脚注追加（「MCP 経由間接利用も公式には不可」）
  - [ ] エグゼクティブサマリーの主要発見の一つとして記録（仮説検証結果）
- **影響範囲**: Anthropic Messages API レイヤ機能（Files API / Citations / Tool search 等）の Claude Code 経由利用可能性が **直接・間接ともに不可** と確定。これにより Agent A §6〜§12 の追加調査は **不要** と判定（期待値ゼロ）
