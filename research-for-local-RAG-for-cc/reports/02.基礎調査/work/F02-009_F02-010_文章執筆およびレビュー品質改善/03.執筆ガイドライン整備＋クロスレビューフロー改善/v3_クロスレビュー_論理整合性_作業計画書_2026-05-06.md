### C1. 打ち切り条件 #1「全検証対象が通過基準を満たさない」と「検証保留」04-03 の論理関係が未定義

#### C1. 問題点

* **概要**: §0.4 / §9.1 の打ち切り条件 #1「04 で **全検証対象が通過基準を満たさない**」と、§5.4.3 04-03 / §5.4.6「Docker 不在環境のため検証保留（除外しない）」の論理関係が定義されておらず、04 完了時の判定が不能になりうる。
* **詳細**:
  1. §5.4.6 は「Docker コンテナ以外の形態で提供されない検証対象は **検証保留**（除外しない）」と規定。04-03 pgvector_MCP は §5.4.3 で「本フェーズでは検証保留」と明記。
  2. 04-03 は §5.4.5 通過基準 #1〜#4 を **そもそも実施しない**（保留）。「全検証対象が通過基準を満たさない」の「全」に 04-03 を含める／含めないの定義が無い。
  3. 04-03 を「全」から除外しなければ、Docker 不在の制約が打ち切り条件 #1 を恒常的に "満たしうる" 状態にする可能性がある。逆に常時除外すれば、04-03 が将来検証されても打ち切り判定に寄与しない。
* **根拠**:
  1. §0.4「**全検証対象が通過基準を満たさない**」（line 67-68）。
  2. §5.4.3「**本フェーズでは検証保留**、別環境で将来検証（Issue `[04][将来解決]` 化対象）」（line 490）。
  3. §5.4.6「Docker コンテナ以外の形態で提供されない検証対象は **検証保留**（除外しない。価値の問題ではなく環境制約のため）」（line 547-548）。
  4. 「打ち切り条件」は承認判断の中核項目（§0.5 / §9.1）であり、定義の曖昧さは承認後の運用判断を直接妨げる（観点 7「承認の押し戻し条件」）。

### C2. 打ち切り条件 #2「全構成が Filesystem Exploration に劣後」が調査目的（トークン削減）と多面判定で論理矛盾

#### C2. 問題点

* **概要**: §0.4 / §9.1 の打ち切り条件 #2「05.有効性検証で **全構成が Filesystem Exploration（grep/glob）に劣後**」は、§0.1 の調査目的「**トークン・コンテキスト消費を、精度を維持したまま最小化**」と照合すると、02.99 §4 H1 の多面判定に矛盾しうる。
* **詳細**:
  1. 02.99 §4 H1 の多面判定では「H1 トークン効率面: **不成立**」=「grep/glob はトークン消費が線形増加し本プロジェクトのゴール（コンテキスト最小化）に反する」。逆に「精度面: 部分成立」=「Codebase-Memory 系より file-explorer が回答品質で 9 ポイント優位」。
  2. v3 §3.1 H1 でも「コードグラフ + シンボル検索が汎用ベクトル検索より **精度・速度・トークン効率** で有利」とトークン効率を含む多面判定を採用しているが、§0.4 #2 の「劣後」が「精度・速度・トークン効率」のどの軸での劣後を指すかが未定義。
  3. 解釈 A（精度面の劣後で打ち切り）: トークン削減目的を達成しても精度劣後で打ち切る → 調査目的（精度維持）と整合。
  4. 解釈 B（総合劣後で打ち切り）: 多面評価で全構成が劣後すれば打ち切る → 何をもって総合劣後と判定するかの算式が §5.5.4 にない。
  5. 解釈 C（単一軸劣後で打ち切り）: トークン効率での劣後だけで打ち切ると、Filesystem Exploration が原理的に低効率（線形増加）な対照群であるため、打ち切り判定がほぼ常時成立しない（条件として無意味化する）。
* **根拠**:
  1. §0.1 目的（line 42）。
  2. §0.4 #2（line 68）「05.有効性検証で **全構成が Filesystem Exploration（grep/glob）に劣後**」。
  3. 02.99 §4 H1 多面判定（line 341-355）「H1 トークン効率面: **不成立** — grep/glob はトークン消費が線形増加し本プロジェクトのゴール（コンテキスト最小化）に反する」。
  4. §3.1 H1（line 179）「精度・速度・トークン効率で有利」（多面評価）。
  5. §5.5.4「対照群（Filesystem Exploration / CAG）に対する優位度」（line 613）が「精度向上度・トークン削減度の差分」と複数指標前提だが、打ち切り判定の合算ルールが無い。
