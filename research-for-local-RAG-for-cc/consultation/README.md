# consultation

このフォルダは、作業指示者が Claude Code と何らかの相談をする際に利用するフォルダ

## 相談時のフォルダ作成ルール

相談をする際には、本フォルダ直下に以下の命名規則に従ったサブフォルダを作成し、その配下に相談の内容を記述したファイルや、相談の中で生成するファイル群を配置する。

* **サブフォルダの命名規則:**  
  `<相談の開始日(YYYYMMDD)+要旨が分かる端的な記述>\`

### 相談中に複数のサブ作業（調査や議論・検討）が発生した場合のルール

サブ作業（ごとに、更にサブサブフォルダを作成し、その中で個々に作業する。  
ただし、サブ作業の内容が1つのファイルで完結する場合は、サブサブフォルダを作る方がコスト高になる可能性もあるので、これは厳守ルールはなく推奨ルール。  

* **サブサブフォルダを作成するか否かの判断基準と作成タイミング**
サブ作業内で生成するファイルが2つ以上になった際に、初めてサブサブフォルダを作成する。

* **サブサブフォルダの命名規則:**  
  `<サブ論点の議論の通番+要旨が分かる端的な記述>\`
