## 執筆ガイドライン参照ルール

本プロジェクトにおける成果物の執筆時は `.claude/skills/writing-guideline/SKILL.md`（執筆ガイドライン）を参照する。本 Skill は `user-invocable: false` かつ以下の `paths:` 条件で **自動ロード**（手動呼び出し不要）:

- `**/reports/**/*.md` — 報告書ファイル編集時
- `**/improvements/**/*.md` — 改善提案ファイル編集時
- `.claude/skills/writing-guideline/**/*.md` — ガイドライン本体編集時

`paths:` は利用者のプロジェクト構成に応じて `SKILL.md` frontmatter で調整すること。

### ガイドラインの使い方

ドキュメント執筆は以下の 3 フェーズで進行する。各フェーズで参照するファイルを意識すること:

| 段階 | 参照ファイル |
|---|---|
| 構造設計（章立て決定） | `references/common/01_構造設計編.md` + 対応する種別ファイル |
| 執筆中 | `references/common/02_執筆中編.md` + 対応する種別ファイル |
| 完成直前のセルフチェック | `references/common/03_完成前セルフチェック編.md` + 対応する種別ファイル |
| 完成後 | `references/執筆者見解レポート.md` を別ファイルとして作成（推奨） |

ドキュメント種別（計画書・調査報告書・レビュー報告書・改訂提案）ごとの固有観点は `references/<種別>.md` を参照。

### クロスレビューとの連携

本ガイドラインは執筆段階の予防チェックリスト、`.claude/templates/cross-review/` 配下のテンプレートは完成版に対する事後チェック。クロスレビュー資産と組み合わせて使用することで、執筆段階で吸収しきれなかった指摘がレビュー段階で発見される双方向品質ループを構築できる。
