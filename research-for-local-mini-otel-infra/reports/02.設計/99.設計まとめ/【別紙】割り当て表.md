<a id="sec-1"></a>
## 1. 割り当て表

列の意味は次のとおりである。

| 列 | 中身 |
|---|---|
| ID | 節の略号と通し番号。a・b は親の箇条の子 |
| 順 | 元の節の中の、箇条の順（段落の決めごとは「段」）。折り込んだ箇条は親の行に含む |
| 計画書の内容 | 原文の意味を変えない短い要約。【推定】・見込みの印は原文のまま |
| 組 | 担当の組。進め方の [§2.1](../00.設計の進め方/計画書.md#sec-2-1) の割り当てによる |
| 決める者 | 「Claude」は設計で決めて設計書の承認で見ていただく。作業指示者の欄は P2-3 の事項または Phase 7 の判断 |
| 時期 | 決める時期。Phase 2 の中の節目・承認時は括弧に書く |
| 設計での状態 | 組の担当が、決めた / 作業指示者に諮る / 決めない理由と時期のどれかを書く。今は「未」 |
| 備考 | 同じ決めごとを指す行、元の箇条の性質など |

## 4. 抜き出しと割り当ての規則

**1 行の数え方**

- 対象の範囲は、計画書の「Phase 2: 設計」から「Phase 3」の前までである。設計項目の表と Phase 3・Phase 7 を待つ 5 つの表は、箇条の要約なので数えない
- 「Phase 2 で決める」「Phase 3 の結果で決める」「Phase 7 の結果で決める」の下の箇条と、「既定の案」の節の箇条を、親（先頭の階層）と子（次の階層）ごとに 1 行にした
- 孫の箇条（3 つ。MT-07e と MT-07g の中の補足）は、親の行に折り込んだ。要約に含めている
- 箇条にならない段落の決めごと（DM-00・MT-00・DD-00・DD-10）は 1 行にした。ほかの段落は、箇条の前置きなので数えない
- 子の箇条は、親が前置きだけの場合と、親の中身を分ける場合がある。どちらも別の行にした（ID の末尾が a・b）
- 計画書 §7 の Phase 2 の行（#3・#5 と、#2・#6 の Phase 2 に残った部分）は、元の節の行と同じ決めごとを指すが、時期の突き合わせのために別の行にした

**割り当ての考え方**

- 組は、[進め方 §2.1](../00.設計の進め方/計画書.md#sec-2-1) の表のとおり、小節ごとに決まる。第二のゴールへの備えは統合にし、正式リリース物の 2 点（AR-03・AR-04）も統合にした
- 決める者は、P2-3 の表の 7 事項に当たる行を作業指示者にした。1 つの行に作業指示者の事項と Claude の事項が混ざる行は、「Claude（一部は作業指示者）」にした。計画書 §7 #7・#8 の Phase 7 の判断（G2-08・G2-09）は、「作業指示者（Phase 7 の判断）」にした
- 時期は、計画書の見出しの区分（Phase 2・Phase 3 の結果・Phase 7 の結果）に従う。Phase 2 の行のうち、実施が Phase 3 以降になるもの（検算、記録の実施など）は、備考に書いた
