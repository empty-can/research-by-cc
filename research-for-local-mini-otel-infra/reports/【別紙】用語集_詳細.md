# 【別紙】用語集_詳細

版: v0.2（変更履歴は [【別紙】改訂履歴_用語集](【別紙】改訂履歴_用語集.md)）

用語集のうち、1 つの Phase の文書にだけ出る語（Phase ごとの節）と、文書のパス、改めた語である。常には読まず、その Phase の作業では節を読み、ほかは grep で探す。定義と「詳しくは」の書き方は核（同じフォルダの `用語集.md`）と同じで、語の定義はどちらか一方にだけ置く。

## 1. Phase 2 の文書の語

Phase 2 の文書（`reports/02.設計/` の下）にだけ出る語である。

| 用語 | 定義 | 詳しくは |
|---|---|---|
| `元の表`・`派生の表` | SQLite の表の種類。元の表は受けた記録を種類ごとに正規化した表、派生の表は取込が元の表から作り直す表 | 定義の別紙 §1.1 |
| `usage_record` | 1 行が API リクエスト 1 件の、集計の正本の表 | 組 B §1.1 |
| `変わったセッション` | その回の取込で、元の表の行が入るか消えたセッションと、計測用のセッションを除く一覧に新しく入ったセッション | 組 B §1.1 |
| `自動開始のターン` | cc が自分で始めたターン | 組 C §0.5 |
| `移譲の区分`・`主の会話のモデル` | 移譲の区分は、品質を分けて出すための区分で、サブエージェントへの移譲と主の会話のモデルの切り替えの有無で分ける。主の会話のモデルは、範囲の `main` の要求で数の最も多い `model_key` | 組 B §2.3 |
| `統合の 12 行` | 割り当て表の行のうち、統合が受け持つ 12 行（正式リリース物の構成と第二のゴールへの備え） | 統合 §7 |
