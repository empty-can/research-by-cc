## 使い方

- **態度表明は、各報告書の「ブロック指摘一覧」の表の「態度表明」列に書く**（採用 / 条件付き採用 / 差戻し / 保留 / 却下）。本書は読むための集約で、本書には記入しない。2026-09-28 の人間読み手の表には「反映先」列もあるので、あわせて見る
- 各 ID のリンクは、報告書の当該指摘の節に飛ぶ（見出しの直前の `<a id>`）
- 多くの指摘は、まとめ報告書 [§5.1 の Q1〜Q5](../99.基礎調査まとめ/報告書.md#sec-5-1) か、[裁定待ち事項](../作業指示者裁定待ち事項.md) の J に判断の中身が移っている。先に Q と J に答え、各指摘にはその回答に沿った態度を書くと手戻りが少ない
- 「前提の変化」列に注記がある指摘は、態度表明の前に注記の参照先を読む
- 同じ論点が複数の報告書にある場合は、「[論点のまとまり](#sec-topics)」を見て、同じ態度をそろえる
- 判断依頼から外れた IMPORTANT 以上の指摘（保留・除外）は、各節の表の下に ID だけ挙げた。異論がある場合は、その報告書の一覧の下に ID とコメントを書く（各報告書の運用）
