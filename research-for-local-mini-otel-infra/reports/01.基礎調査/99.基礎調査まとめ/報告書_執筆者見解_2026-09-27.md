## 4. 見直しで直した誤り

v0.1 の時点（見直し前）に、次の 4 件を直した。いずれも事実の確認で誤りと判明したもの。

- 1-1: 「hook 系のイベントは対話モードでだけ出る」→ hook を設定したセッションでは `-p` でも出るので訂正した
- 1-1: 「`assistant_response` は docs の一覧に無い」→ docs に記載があるので訂正した
- 1-1・別紙: 「`speed` は docs と差異あり」→ イベントの docs は `fast` / `normal` と定義しており、一致に訂正した（V-11(b) #30）
- まとめ: (B) を外す理由から「行順を時系列の根拠にできない（v2.1 R-4）」を外した。どの構成にも当てはまる事実なので、横断事項（§2 の 10）へ移した

今回の見直しでは、事実・判断の変更は無い。1-3 の「hook の `prompt_id` が 7 件すべてで一致」は、受信データで再集計して正しいことを確認した。

## 5. レビューアへの補足（設計意図）

- 実測データ（受信した JSONL、受信スクリプト）は repo 外に置いた。報告書には件数・キー名・型だけを書き、実値は書いていない。根拠の再現には、1-1 §1 の実行パターンを再実行する必要がある
- 「Claude の所見」「推奨」は、判断材料と区別するため、1-2 §5 とまとめ §5.1 に限って書いた。判断は作業指示者に委ねる前提である
- 1-1 §7 の「起動方法による差」は原因を特定できていない。本番の有効化方法（ユーザ settings）には影響しないため、原因の追及は打ち切った
