# cross-review テンプレート

クロスレビュー報告書の雛型。3 種同梱:

| ファイル | 担当レビュアー | 観点（既定） |
|---|---|---|
| `論理整合性_template.md` | Claude Opus（独立第三者） | 論理整合性・カバレッジ十分性・調査目的との整合性・仮説の妥当性 |
| `実用性_template.md` | Claude Sonnet（独立第三者） | 完了条件明瞭性・命名規則遵守・文書構造・検証パターン具体性 |
| `作業指示者レビュー_template.md` | 作業指示者（人間） | 自由記入。観点欄は記入時に補足。 |

## 使い方

1. レビュー対象のフェーズ配下に `レビュー/` フォルダを作成
2. 上記 3 ファイルを `<観点名>_<日付YYYY-MM-DD>.md` の名前でコピー
   - 例: `クロスレビュー_論理整合性_2026-05-01.md`
3. 各ファイル冒頭の `{{...}}` プレースホルダを埋める
4. Opus / Sonnet レビューは Agent に委任（`.claude/skills/orchestrate/` のパターン A: 並列調査を参照）
5. 作業指示者レビューは作業指示者が直接記入

## 設計方針

- **指摘エントリごとに「作業指示者の態度表明」テーブルを内蔵** — 指摘とその態度を 1 箇所にまとめ、別ファイルやドキュメント末尾を行き来する負担を排除
- **接頭辞で出所を区別** — `C/I/S/P` (論理) / `C-/I-/S-/P-` (実用) / `U-C/U-I/U-S/U-P` (作業指示者)
- **件数サマリは記入完了後に更新** — 雛型では `<TBD>` プレースホルダ
- **変更履歴セクションを末尾に必ず保持** — 改訂履歴の追跡は各ファイル内で完結させる方針
