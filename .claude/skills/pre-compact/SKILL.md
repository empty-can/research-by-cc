# pre-compact（コンパクション前事前準備）

`/compact` 実行前に呼び出し、コンパクション後の次セッション再開時に最低限の文脈が復元できる状態を整える Skill。

## 実行手順

以下を順番に実施する。

### 1. メモリ最新化

auto-memory（`memory/` ディレクトリ）配下のメモリファイルを確認し、現在の会話で変化した情報を更新する。確認観点:

- 進行中のタスクの最新ステータス・中断箇所
- 次セッション再開時の継続ポイント
- 作業指示者との合意事項で未記録のもの
- 保留中の判断事項

### 2. 未コミット変更の確認

`git status` で未コミット変更を確認する。変更がある場合はコミットメッセージ案と対象ファイルを提示し、作業指示者の判断を仰ぐ。

### 3. 継続ポイントの提示

次セッション再開時に必要な情報を簡潔に提示する:

- 現在実施中のタスクと中断箇所
- 保留中の判断事項（作業指示者が決める必要があるもの）
- 次セッションの最初のアクション

## 完了確認

上記 3 ステップが完了したら「`/compact` を実行してください」と作業指示者に伝える。

## 設計背景

`/compact` は built-in コマンドであり `PreCompact` hook で前処理を挟む方法があるが、hook は Claude のコンテキスト外（シェル/別 LLM 呼び出し）で動作するため、現在の会話コンテキストを踏まえた Claude 自身による能動的な準備は実行できない。詳細は `references/decision-flow.md` §2.1 参照。
