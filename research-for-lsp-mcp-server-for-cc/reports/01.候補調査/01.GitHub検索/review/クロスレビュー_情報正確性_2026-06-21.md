## 補足事項

### nzrsky/lsp-mcp-server の pushed_at 乖離について（重大度: 高）

- 候補_D_レジストリ横断.md と 候補一覧.md（統合版）の両方に「2026-04-16」と記載されているが、GitHub API の `pushed_at` は `2025-12-07T11:05:42Z`。
- 2025-12-07 は半年基準日（2025-12-21）の **14日前** であり、半年以内（✅）ではなく停滞（❌）に分類されるべき候補。
- この乖離により候補一覧.md での「✅半年以内」判定が誤り。Phase 2 ショートリストでは Tier 2 に位置づけられているが、正確には停滞候補として再評価が必要。
- nzrsky/lsp-mcp-server の README には Java=`jdtls` が明記されており、Java 対応の記載自体は確認できた。

### sunix/java-lsp-mcp-server の Java 要件乖離について（重大度: 高）

- 候補_B_Java特化.md に「Java 25必須」と明記されているが、pom.xml の `maven.compiler.release=17` はコンパイルターゲットが Java 17 であることを示す。
- ただし pom.xml はコンパイル時のターゲットバージョンであり、実行時の最小 JDK バージョンが 17 であることを意味する（25 ではない）。
- Java 25 という記述の出典は README またはドキュメントの別箇所の可能性がある。今回は pom.xml のみ確認したため、README に別途「JDK 25」の記述がある場合の確認は未実施。pom.xml との乖離は確定。

- レポートの「MIT」は README を根拠とした記載と解釈でき、情報として誤りとまでは言えない。ただし正式な LICENSE ファイルが未存在のため、ライセンスの法的有効性は曖昧。
